# MCP

Model Context Protocol server configs and setup notes, shared across agents.

One file per server (config block + env vars + auth + gotchas). Install by
copying the relevant block into the agent's MCP config:

- **Claude Code** — `~/.claude/mcp.json` or a project `.mcp.json`
- **VS Code** — `.vscode/mcp.json`
- **Codex** — `~/.codex/config.toml`

> Populated as servers are added.
