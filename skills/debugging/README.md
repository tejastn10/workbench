# skills/debugging

Investigation and incident skills. Shared discipline with the PR-review skills:
**show the mechanism, not the symptom** — trace it before you claim it.

| Skill                       | Use for                                              |
| --------------------------- | -------------------------------------------------- |
| `investigate-bug.md`        | Working a bug: reproduce → isolate → hypothesis → trace → fix at the right altitude |
| `write-incident-report.md`  | Blameless postmortem after a user-facing failure (template `POSTMORTEM.md`) |

A bug with user-facing impact goes: `investigate-bug` → fix → `write-incident-report`.
