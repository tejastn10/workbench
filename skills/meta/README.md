# skills/meta

Maintaining the workbench itself, and building review skills from real corpora.

| Skill                     | Use for                                                   |
| ------------------------- | ----------------------------------------------------- |
| `meta/write-skill`          | Author a new skill in the house style (frontmatter, terse body, anti-patterns) |
| `meta/audit-skills`         | Periodic rot check — dead links, stale paths, tooling/convention drift |
| `meta/distill-review-style` | Build a `pr-review/<stack>` skill from a `gh`-pulled corpus of your own PR comments (run on the machine with repo access) |
